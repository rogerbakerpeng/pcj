# 需求测试资料

每个需求一个目录，记录从确认到沉淀的全过程；沉淀完成后只读，作为历史记录。

```
requirements/<日期>_<需求名>/      如：20261104_会员端实名认证优化
├── 需求文档.docx       交付提供的原始需求（脱敏后）
├── 01_确认项.md        第一步：AI 生成，交付和研发填写答复
├── 02_测试用例.md      第二步：AI 生成，交付审核后作为验收标准
├── 自测报告.md         研发 AI 编码自测后生成，提测时附上
├── 03_验收记录.md      交付验收结论和问题，每个问题标注返工分类（模板见 docs/模板/）
└── 04_沉淀记录.md      第三步：哪些用例进了用例库和回归、改了哪些旧用例
```
